# Effect balance across all nine play styles

Each row tests one effect on a fresh play. Hand sizes 1–5 are equally likely, and physical roll probabilities determine how often each style occurs. The player commits to the selected dice before rolling. For Guardian, Power Reserve and Paid Leave the equipped die is held whenever there is room, and played at five dice.

**Net/play** is the mean score difference from a fully plain build, including face changes. **Gain %** counts rolls where the effect adds points on the same faces. Each style column shows mean extra points on those faces, conditional on rolling that input style. Missing Link promotions count under their original style. Ranks compare all three families.
