# Bonus and Joker icons

Complete first SVG set: **29 bonuses + 28 Jokers**, using the agreed English/French
names. Game display names are updated; internal IDs and mechanics are unchanged.
The artwork is ready for review and is not yet wired into game scenes.

- [Bonus review sheet](bonuses-review.png)
- [Joker review sheet](jokers-review.png)
- [Machine-readable catalog](catalog.json): stable ID, family, localized names, SVG path.

All icons have a 512 × 512 viewBox and a transparent background. They use the
existing Paroli palette, rounded plum outlines, cream highlights, and explicit
vector geometry. No fonts, raster images, external references, or SVG filters.
Each review card includes a 48-pixel sample.

Odd/Even Button share the same drawing with three/four holes. Odd/Even Squad
share helmets, with three/four members and one/two dots on their badges. Trio
is three tiny dice. Borderline / La frontière is the accepted fresh alternative for
Extremities. Missing Link preserves the approved original study exactly.

The original `pocket_money.svg` and `preview.png` remain historical studies;
Payday now uses a pay envelope, not a pocket. The top-level `missing_link.svg`
is the approved original, copied into the Joker set.

## Editing and validation

The SVGs can be edited directly. `author_icons.py` records the hand-authored
geometry and shared drawing primitives; it is an optional authoring tool, not
a game import dependency. If editing SVGs directly, preserve those edits before
rerunning the authoring script.

```sh
python docs/art_explorations/effect_icons/author_icons.py
python docs/art_explorations/effect_icons/render_review.py
python godot/mechanics/tests/check_catalog.py
```

The review renderer uses librsvg and Pillow. It verifies viewBoxes, rejects
external dependencies, checks transparent silhouette bounds, and renders every
icon. Full-size intermediate PNGs are written to `/tmp/paroli-effect-icons`.


### Dés des icônes

Tous les dés des SVG ont des faces mates, sans aucun trait de reflet lumineux
(droit, perpendiculaire ou courbe). Cette règle est portée par la primitive
`die()` de `author_icons.py` et concerne les bonus comme les jokers.
Elle ne modifie pas les finitions des dés 3D du jeu.
